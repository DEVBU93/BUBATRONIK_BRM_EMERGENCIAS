## Criterio de uso

- Las fuentes oficiales son la referencia para instrucciones y avisos.
- Las fuentes de observación ayudan a descubrir y contextualizar eventos.
- BRM añade una capa de presentación, trazabilidad y contexto; no debe alterar el significado de una alerta oficial.
- Protección Civil/RAN se usa como contexto institucional oficial; BRM no reproduce ni reinterpreta ES-Alert como si emitiera alertas propias.
- Si una fuente deja de estar disponible, la interfaz debe mostrar la situación en lugar de simular conectividad.
